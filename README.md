# PyQR (PyQuantumRefactor)

## Overview 
PyQuantumRefactor is a tool created to answer a specific research question: 
*"Can a local large language model be used to assist the migration of pre-quantum cryptography code to a post-quantum version while preserving functional correctness?"*

The project focuses on the creation of a working pipeline that combines static analysis of a codebase together with a dynamic LLM-based evaluation of code fragments to produce
 cryptography risk scores, Cryptography Bill of Materials (CBOM), and a Post-Quantum compliant refactored code.

The objective is not merely to generate syntactically valid code, but to deliver modifications that remain fully executable and preserve pre-existing functionalities.
